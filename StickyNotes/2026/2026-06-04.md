# Topicos de mais atenção

### Holdout e amostragem aleatoria 
esse metodo divide em 3 partes os dados train, val, 

**VANTAGEM**: **Holdout Estratificado** é unir a velocidade do metodo a uma forma de avaliar mais justa em dataset desbalanceados -> preserva a proporção das classes

**DESVANTAGEM**: **Holdout Estratificado** é performance depende de uma unica divisão de dados o que vai gerar uma estimativa com alta variândia -> menos robustes q a validação crusada

### K-fold (Cross-validation)
esse metodo faz o modelo dividir em k partes (folds) sendo comum o padrao ter 10 partes e sempre é feito a cada interação k-1 partes para ser trainado 

**VANTAGEM:** ser mais robusto que o holdout
**DESVANTAGEM:** ser mais custoso computacionalmente principalemnte a datasets  desbalaceados

### Cross-validation

definimos o numero de interações e fazendo uma amostragem com repetição dos valores o q não entrar na bag vai para oob e sera usado com teste

**VANTAGEM:** Estivar a escabilidade e a variancia de modelos, **_MUITO BOM PARA DATASETS PEQUENOS_** pela reutilização dos dados => gerar distribuição de metricas, visão geral e mais completa da performance do que um unico split dos dados

**DESVANTAGENS:** mais custoso computacional pois tem q treinar muitos modelos e sua complexidade conceitual => POR TER REPETIÇÃO ESTA SUJEITO A SER SENSIVEL A OUTLIERS POIS PODEM ESTA SUPER REPRESENTADO EM ALGUMAS AMOSTRAS
