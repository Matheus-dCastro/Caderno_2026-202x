# Customizações do Ubuntu (Novo PC)

- [ ] **GDM Settings (Tela de Login)**
  - Mudar o wallpaper da tela de início
  - Remover o logo do Ubuntu
  - Comando para ativar o tema:
    ```bash
    sudo update-alternatives --set gdm-theme.gresource /usr/share/gnome-shell/gnome-shell-theme.gresource
    ```

- [ ] **GNOME Tweaks (Ajustes)**
  - Mudar a fonte global do sistema para a fonte **Maple Mono**
  - mudar o cursor

- [ ] **DBeaver CE**
  - Instalar o **DBeaver Community Edition**
